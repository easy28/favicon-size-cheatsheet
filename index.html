2 · Which file format?

FormatUse it forCaveat
.icoThe root /favicon.ico fallback every browser still requestsOnly format some legacy tools read — bundle 16/32/48 inside one file: PNG→ICO · SVG→ICO
.pngModern <link rel="icon"> sizes, touch icons, manifest iconsTransparency fine everywhere except apple-touch-icon
.svgOne scalable icon for supporting browsers — smallest maintenanceSafari only reads it via the mask-icon mechanism; details in SVG vs PNG favicons
.jpgNothing — no transparency, larger filesBut if a logo only exists as JPG, convert it: JPG→favicon set
Rule of thumb: ship one .ico fallback + two PNGs (192, 512) + one 180 apple-touch-icon + (optionally) one SVG. That's five files, and it covers every browser, OS and store listing that matters in 2026.

3 · The minimal copy-paste tag set

<!-- Fallback for everything old -->
<link rel="icon" href="/favicon.ico" sizes="48x48">

<!-- Modern scalable icon -->
<link rel="icon" href="/icon.svg" type="image/svg+xml">

<!-- High-DPI PNG sizes -->
<link rel="icon" href="/icon-192.png" type="image/png" sizes="192x192">
<link rel="icon" href="/icon-512.png" type="image/png" sizes="512x512">

<!-- iOS home screen -->
<link rel="apple-touch-icon" href="/apple-touch-icon.png">

4 · apple-touch-icon specifics (the one iOS reads)

  • One file, 180×180, named apple-touch-icon.png at your site root — iOS finds it without a tag (a tag helps Android/Chrome pick it up too)
  • No transparency — iOS composites transparent pixels onto black; export on your brand background
  • No rounding needed — iOS applies its own mask; pre-rounding gives you double-rounded corners
  • Full walkthrough with every gotcha: the apple-touch-icon guide

5 · PWA / Android notes

  • Web app manifest requires 192×192 and 512×512 PNGs — generate: 192 · 512
  • Add "purpose": "maskable" variants with ~10% safe-zone padding so Android's circle mask doesn't crop your edges
  • Splash screens are built from the 512 icon + manifest background_color/theme_color
  • Safari desktop dark-mode rendering is a separate mechanism: mask-icon & dark mode in Safari
